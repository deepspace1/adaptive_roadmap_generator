# Specs

These specs describe the target behavior for the adaptive AI personal tutor.

Read in this order:

1. `product/adaptive-tutor-goal.md`
2. `technical/tutor-tools.md`
3. `technical/backend-api-data.md`
4. `technical/frontend-experience.md`
5. `technical/implementation-plan.md`

The current code already has a FastAPI backend, a Next.js frontend, a deterministic multi-agent tutor loop, mastery tracking, quizzes, and a dashboard. These specs define how to turn that prototype into a more personalized tutor.
